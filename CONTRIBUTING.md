# Contributing

Follow [Anthony Fu's contribution guide](https://github.com/antfu/contribute) and any repository-specific instructions.

## AI-assisted contributions

Before starting work, agents must read this guide and the target repository's instructions.

- A human owns the submission and remains responsible for it.
- Never publish text as Harlan or claim his personal approval.
- If an agent drafts public text, identify it and link to [Harlan's AI policy](https://harlanzw.com/blog/ai-in-open-source).
- Keep pull request descriptions concise and follow the [PR contract](https://github.com/harlan-zw/harlan-agent-kit/blob/main/harlan-agent-kit/skills/pr/SKILL.md).
- Agent reviews follow the [adversarial review contract](https://github.com/harlan-zw/harlan-agent-kit/blob/main/harlan-agent-kit/skills/adversarial-review/SKILL.md) and use one labelled bot comment.
- Never approve or merge a pull request.
- Use normal commits. Never amend published commits, force push or hide history.
- Never push to the default branch. Only Harlan Agent Kit's [PR owner](https://github.com/harlan-zw/harlan-agent-kit/blob/main/harlan-agent-kit/skills/pr-owner/SKILL.md) may use its documented post-merge exception.
- For sites, the PR owner watches deployment and runs relevant production smoke tests.
- If authority or intent is unclear, stop and ask Harlan.
